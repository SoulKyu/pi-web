# pi-web UI/UX sprints — design

Source: three-model ideation + cross-review, consolidated by the controller. Full material (ideas, reviews, verified objections): `/home/ubuntu/reports/pi-web-agentic/ux/` (`ideas-{fable,opus,glm}.md`, `review-*.md`, `index.html`). This document is the binding authority; where an idea file and this document disagree, this document wins.

## Scope (binding)

UI/UX only. Allowed: `components/**`, `hooks/**`, `app/globals.css`, `lib/i18n/messages/{en,fr,zh-CN,zh-TW}.ts`, new client-safe pure helpers under `lib/` or `components/` that only shape display, their `.test.mjs` files, and `docs/agents/*.md` notes for the areas touched.
Forbidden: new or changed API routes, server logic, session format, agent runtime, security/permission behaviour, new npm dependencies, build tooling, `package.json`.

## Global constraints (binding)

1. Old Safari iOS 16.2: no RegExp lookbehind (`(?<=`, `(?<!`) in client code; no API newer than Safari 16.2. `color-mix()`, `scrollIntoView({ block, inline })`, `@media (pointer: coarse)`, Pointer Events are allowed.
2. Every visible string through `useI18n()` with the key present in all four of `lib/i18n/messages/{en,fr,zh-CN,zh-TW}.ts`.
3. Accessibility: keyboard reachable, visible focus, accessible names, `prefers-reduced-motion: reduce` honoured by any new animation, information never carried by colour alone.
4. Mobile first-class: behaviour at ≤ 640 px and with the software keyboard open (`useViewportHeight`, `data-keyboard-open`) must be stated and work.
5. Escape inside any new popover/dialog calls `event.preventDefault()` (otherwise `handleGlobalEscape` in `hooks/useKeyboardShortcuts.ts` stops the running agent). New dialogs/popovers use `role="dialog"` so `hooks/useRailShortcuts.ts` stands down.
6. Long sessions: no new prop to `MessageView` whose identity changes on every streamed token or tool progress tick (`MessageView` is `memo()`ed).
7. Tests: `.test.mjs`, no TypeScript syntax, `node:test`; run with `env -i PATH="$PATH" HOME="$HOME" LANG="$LANG" node --experimental-strip-types --test …`. `node --test` treats `[name]` in a path as a glob. Every new pure helper gets one test file. Existing source-assertion tests (`components/agents/AgentRail.test.mjs`, `components/MobilePwaLayout.test.mjs`, etc.) updated when markup they assert changes.
8. Gates: `node_modules/.bin/tsc --noEmit`, `npm run lint`, the full suite (one known pre-existing failure: `lib/codemode-settings.test.mjs` "the mode is read as the codemode extension reads it").
9. Conventional Commits, no AI attribution, explicit `git add <paths>`, never `.superpowers/`. Never `next build` or `next dev` in the worktree.
10. Windows paths: any path splitting goes through `normalizeFilePathSlashes` from `lib/file-paths.ts`.

## Sprint 1 — small wins (all S)

- **A. File tabs: same-name disambiguation + active tab scrolled into view.** Pure helper (`components/tab-labels.ts`, + test) returning, for file tabs sharing a `label`, the shortest parent-path suffix that makes them unique (cap 2 segments, `…/` prefix beyond). Skip terminal tabs and non-closable pseudo-tabs (Agent tab). Render the suffix dimmed (`var(--text-dim)`) after the name in `components/TabBar.tsx`, include it in the tab's accessible name; the name keeps priority when truncating. Effect on `activeTabId`: active tab `scrollIntoView({ block: "nearest", inline: "nearest" })` (smooth only without reduced motion). Evidence: `components/file-tab-state.ts:18`, `components/TabBar.tsx:42,93-94,113-116`.
- **B. One theme-aware diff palette.** CSS variables `--diff-added`, `--diff-removed`, `--diff-added-bg`, `--diff-removed-bg` (bg via `color-mix(in srgb, var(--diff-x) 14%, transparent)`) defined for `:root` and each `[data-theme]` block (light, dark, mist, rose, pine; `auto` resolves to one), marker contrast ≥ 3:1 against that theme's `--bg`. Replace literals in `components/MessageView.tsx` `SplitDiffCellView` (~1503-1519) and `PatchTextView` (~1568-1596) and `components/FileViewer.tsx` `DiffView` (~367-397). Tool success/error borders (`MessageView.tsx` ~1276, ~1686, ~1730) are NOT diff semantics: leave them untouched in this item. No legend.
- **C. Task-card header wraps.** `components/agents/AgentTasks.tsx:38-53` and the trigger header in `components/agents/AgentTriggers.tsx` (~149-154): inline `flexWrap: "wrap"`, `rowGap`, title `flex: "1 1 100%"` (or `1 1 12em`) with `minWidth: 0`, at every width (no media query: the right panel is resizable on desktop). No new wrapper span; DOM order unchanged.
- **D. Daily budget progress bars.** In `components/agents/AgentSpaceRight.tsx` (~104-133) replace the parenthesised `budgetSuffix` with one labelled native `<progress>` per configured budget (tokens, cost), figures to its right. Render only when cap > 0; a cap of 0 shows the existing "budget reached" text only. Style via `appearance: none` + `::-webkit-progress-bar` / `::-webkit-progress-value` / `::-moz-progress-bar` using theme variables (do not rely on `accent-color`). Cost label says provider cost. i18n `agents.usage.budgetTokens`, `agents.usage.budgetCost`.
- **E. Visible shortcut hints.** Pure helper (`lib/shortcut-label.ts`, + test) formatting a chord for the platform (macOS `⌃⌥`, else `Ctrl+Alt`). Stop button title/label shows `(Esc)`; new-session title shows the Ctrl+Alt+N chord; desktop follow-up button (`components/ChatInput.tsx` ~2325-2326) renders a small `<kbd>` with its chord; nothing on mobile. Update `chat.stopAgent` / `sidebar.newSessionTitle` (or add hint keys) in all 4 locales.
- **F. Micro-accessibility.** (1) `aria-live="polite"` + `role="status"` on the agent phase label (`components/ChatWindow.tsx` ~1363-1373, both `phaseLabel` and the bash-running line). (2) Sidebar search (`components/SessionSidebar.tsx` ~1469-1473): Escape on an already-empty query closes the search and returns focus to its toggle button. (3) Rail pause (`components/agents/AgentRail.tsx:130`): replace `window.confirm` with an inline two-button confirmation (pattern: session delete confirm in `SessionSidebar.tsx` ~2354-2392), Escape cancels with `preventDefault`.
- **G. Reduced-motion sweep.** One `@media (prefers-reduced-motion: reduce)` rule covering `blink`, `pulse`, `spin` keyframe users and the Tailwind inline `animate-[pulse_1.5s_infinite]` (`ChatWindow.tsx` ~1365, ~1371) — e.g. a class or attribute selector; CSS only.

## Sprint 2 — medium items

- **H. Rail health popover.** Replace the 8 px health `<span>` (`AgentRail.tsx:155`) with a button (32 px hit area, 44 px under `pointer: coarse`) keeping the dot visually. Toggle a `role="dialog"` popover rendered OUTSIDE the scrolling `<nav>` (the rail has `overflow-x: auto`, `globals.css:1870,1879`): `position: fixed` from `getBoundingClientRect()`, clamped to the viewport, right of the vertical rail / below the horizontal one. Lines: level, last tick, running isolated+thread, free MB, sessionsAlive when present, quiet hours, first extension error, pause error (moved from the title-only ⚠ at `:158`), stale notice when present. Close on Escape (preventDefault, focus back to the button), outside pointerdown, second click. Rail buttons 44 px under `pointer: coarse`. Update `AgentRail.test.mjs`.
- **I. Tool card status in text + icon.** In `MessageView.tsx` `ToolCallBlock` (~1200-1310): status `running | done | failed | none` — running = id in the running set; done = result and not running; failed = existing `isError`; none = no result, not running, message not streaming. Running: neutral border `var(--border)`, spinner (`@keyframes spin`, static under reduced motion), text "Running…"; failed: ✕ + visible "Failed"; none: "–" + "No result"; done: ✓ (word for screen readers only). Glyph `aria-hidden`; `aria-expanded` on the header button. Below 400 px the word collapses to the glyph (glyph then gets an accessible name). The running id set is passed from `ChatWindow` with identity stable across progress ticks: keep it in a ref and replace it only when membership changes (constraint 6). Special agent cards that return early stay unchanged. i18n `chat.toolStatus.{running,done,failed,noResult}`.
- **J. Session rows reachable by keyboard and touch.** `SessionSidebar.tsx` `SessionItem` (~2300-2540): row `tabIndex={0}`, `role="button"`, `aria-current` when selected, `aria-label` (title + relative time + running/unread). Keys on the row itself (`event.target === event.currentTarget`): Enter/Space open, F2 rename, Delete opens the existing inline delete confirmation, ArrowUp/Down move focus to the previous/next row (scroll first, focus in `requestAnimationFrame`; the virtual list already keeps the focused index mounted). Actions visible on `hovered || focusWithin || coarse pointer`; on coarse pointer a single 32 px `⋯` button toggles an inline Rename/Delete strip in the same row height. `aria-label` on icon buttons. Rename/delete failures (today `catch {}`) show an inline `role="status"` error for 4 s. Focus ring `:focus-visible` with `var(--accent)`. i18n `sidebar.moreActions`, `sidebar.renameFailed`, `sidebar.deleteFailed`, `sidebar.sessionRowLabel`.
- **K. "Draft restored" chip.** `ChatInput.tsx`: a `draftRestored` flag set only by the two restore-from-storage paths (lazy `useState` initializer ~625-630 and the `draftKey` swap effect ~932-955) when the restored text or images are non-empty; never by `rekeyDraft` (~738-760). Chip in flow above the textarea with ✕ only; cleared on ✕, send, or the composer becoming empty. i18n `chat.draftRestored`, `chat.draftDismiss`.
- **L. Next-fire hint on trigger cards.** `components/agents/AgentTriggers.tsx` + `components/agents/trigger-view.ts` (pure, tested): `everyMinutes` → "≈ in N min" from `lastFireAt` (or "≈ soon" when overdue/unknown); `at` → "daily HH:MM (server time)" without timezone conversion; both when both set; nothing for webhook/feed-only or disabled triggers. Prefix ≈ (quiet hours and the 60 s tick shift fires). i18n keys × 4.

## Sprint 3 — larger items

- **M. Keyboard shortcuts dialog.** New `components/ShortcutsDialog.tsx`, static grouped table (Global: Esc, Ctrl+Alt+N, ?; Agents: Alt+↑/↓, Ctrl+Alt+1..9; Composer: send chord derived from `useEnterSendMode()` + `useIsMobile()`, Alt+Enter follow-up; File tabs: ←/→/Home/End). No rows for `@` or `/` syntax. Opened by `?` (`e.key === "?"`, not in input/textarea/contenteditable, no `[role="dialog"]` open), by a link in Settings › General, and by an entry in the mobile toolbar actions. `role="dialog"`, `aria-modal`, focus trap via `lib/stacked-dialog.ts` helpers, Escape with preventDefault. Reuses the Sprint 1 E chord helper.
- **N. Agent identity in the horizontal rail.** In horizontal orientation (mobile), show the agent name (truncated, ≤ 8 chars visual width, ellipsis) under each avatar; vertical rail unchanged. No long-press in this sprint (ruling: CSS alternative first).
- **O. Find in this session.** A magnifier button in the floating cluster next to scroll-to-bottom opens a bar above the composer (in flow, input font ≥ 16 px on mobile). Pure helper `lib/chat-find.ts` (+ test): case-insensitive substring over loaded messages (user text, assistant text blocks) → ordered `{ entryId, blockIndex? }[]`. Enter / › next, Shift+Enter / ‹ previous, wraps; counter `n/m` + "loaded messages only" note. Jumping reuses the existing scroll-and-flash path by letting `ChatWindow` set the search target: add an `onRequestSearchTarget` callback prop that `AppShell` wires to its `setSearchTarget` (same shape `{ sessionId, entryId, blockIndex? }`). Scan memo gated while the session is streaming (recompute when the run ends or the query changes). No Ctrl+F binding. Escape closes the bar (input element, so the global Escape does not fire; still preventDefault). No sidebar handoff in v1.
- **P. Prompt length counter (Queue task dialog).** `components/agents/QueueTaskDialog.tsx`: client mirror `PROMPT_MAX = 20_000` (comment pointing to `app/api/agents/[name]/tasks/route.ts`); counter shown above 50 %, exact `Intl.NumberFormat` figures; over the cap: Queue disabled + visible `role="alert"` reason; the counter itself is not a live region. Server stays authoritative.
