## Global Constraints

Copied verbatim from the spec's "Global constraints (binding)":

1. Old Safari iOS 16.2: no RegExp lookbehind (`(?<=`, `(?<!`) in client code; no API newer than Safari 16.2. `color-mix()`, `scrollIntoView({ block, inline })`, `@media (pointer: coarse)`, Pointer Events are allowed.
2. Every visible string through `useI18n()` with the key present in all four of `lib/i18n/messages/{en,fr,zh-CN,zh-TW}.ts`.
3. Accessibility: keyboard reachable, visible focus, accessible names, `prefers-reduced-motion: reduce` honoured by any new animation, information never carried by colour alone.
4. Mobile first-class: behaviour at ≤ 640 px and with the software keyboard open (`useViewportHeight`, `data-keyboard-open`) must be stated and work.
5. Escape inside any new popover/dialog calls `event.preventDefault()` (otherwise `handleGlobalEscape` in `hooks/useKeyboardShortcuts.ts` stops the running agent). New dialogs/popovers use `role="dialog"` so `hooks/useRailShortcuts.ts` stands down.
6. Long sessions: no new prop to `MessageView` whose identity changes on every streamed token or tool progress tick (`MessageView` is `memo()`ed).
7. Tests: `.test.mjs`, no TypeScript syntax, `node:test`; run with `env -i PATH="$PATH" HOME="$HOME" LANG="$LANG" node --experimental-strip-types --test …`. `node --test` treats `[name]` in a path as a glob. Every new pure helper gets one test file. Existing source-assertion tests (`components/agents/AgentRail.test.mjs`, `components/MobilePwaLayout.test.mjs`, etc.) updated when markup they assert changes.
8. Gates: `node_modules/.bin/tsc --noEmit`, `npm run lint`, the full suite (one known pre-existing failure: `lib/codemode-settings.test.mjs` "the mode is read as the codemode extension reads it").
9. Conventional Commits, no AI attribution, explicit `git add <paths>`, never `.superpowers/`. Never `next build` or `next dev` in the worktree.
10. Windows paths: any path splitting goes through `normalizeFilePathSlashes` from `lib/file-paths.ts`.

Scope (binding, from the spec): only `components/**`, `hooks/**`, `app/globals.css`, `lib/i18n/messages/{en,fr,zh-CN,zh-TW}.ts`, new client-safe pure helpers, their tests, and `docs/agents/*.md` notes for the areas touched.

## Review Focus

These are the five cases most likely to hurt a real user that the spec implies but does not test directly. Each one now has a test in its owning task.

- **A tool call waiting its turn during a live run** (the model asked for several tools; the second has no result and is not running yet) must show no status at all, not "No result" for the whole run. The test lives in Task 2: `runActive: true` with no result renders no `tool-status`.
- **Escape while the health popover is open, with an agent running**, must only close the popover and return focus to the dot. The run must keep going. The test lives in Task 1: a source assertion that the `document` keydown listener calls `preventDefault()` before `closeHealth(true)`, so `handleGlobalEscape` on `window` sees `defaultPrevented`.
- **Delete or Shift+Delete on a focused session row** must open the inline confirmation, never delete directly. The repo once removed a "Shift+Delete deletes without confirmation" shortcut. The test lives in Task 3: the row key handler has no `performDelete` and no `shiftKey`.
- **An interval trigger created or fired in the middle of its interval** must show the real next fire. The scheduler fires on epoch-aligned buckets (`lib/agent-ops/scheduler.ts:289-292`), not at last fire + interval. The test lives in Task 5: a fire at 10:23 on a 60-minute trigger reads "in 37 min" at 10:23, not "in 60 min".
- **Switching to another session, or a new chat getting its session id (`rekeyDraft`)**, must not show or carry over "Draft restored". The test lives in Task 4: the swap effect sets the flag from that session's draft (false when it has none), and `rekeyDraft` never touches it.

```ts
import type { AgentOpsHealth } from "@/lib/agent-ops/health";
import type { TranslationParams } from "@/lib/i18n/types";

type Translate = (key: string, params?: TranslationParams) => string;

const GAP = 8;
const MARGIN = 8;

/** What the rail health popover says, one line per fact; gauges the server did not send are left out. */
export function healthPopoverLines(
  state: { health: AgentOpsHealth; level: "ok" | "warn" | "down" } | null,
  extras: { pauseError: string | null; staleTime: string | null },
  t: Translate,
  formatTime: (iso: string) => string,
): string[] {
  const lines: string[] = [];
  if (state) {
    const { health } = state;
    lines.push(t(`agents.health.${state.level}`));
    lines.push(t("agents.health.lastTick", { time: health.lastTickAt ? formatTime(health.lastTickAt) : "–" }));
    lines.push(t("agents.health.running", { isolated: health.running.isolated, thread: health.running.thread }));
    lines.push(t("agents.health.freeMemory", { freeMb: health.freeMb ?? "–" }));
    if (typeof health.sessionsAlive === "number") lines.push(t("agents.health.sessions", { count: health.sessionsAlive }));
    if (health.quietHours) lines.push(t("agentOps.quietHours.active"));
    const extensionError = health.extensionErrors[0]?.text;
    if (extensionError) lines.push(t("agents.health.extensionError", { text: extensionError }));
  }
  if (extras.pauseError) lines.push(t("agents.error", { error: extras.pauseError }));
  if (extras.staleTime) lines.push(t("agents.rail.stale", { time: extras.staleTime }));
  return lines;
}

/** Fixed position beside the rail button: right of the vertical rail, below the horizontal one, kept MARGIN px inside the viewport. */
export function healthPopoverPosition(
  anchor: { top: number; right: number; bottom: number; left: number },
  size: { width: number; height: number },
  viewport: { width: number; height: number },
  orientation: "vertical" | "horizontal",
): { top: number; left: number } {
  const top = orientation === "vertical" ? anchor.top : anchor.bottom + GAP;
  const left = orientation === "vertical" ? anchor.right + GAP : anchor.left;
  const clamp = (value: number, extent: number, limit: number) => Math.max(MARGIN, Math.min(value, limit - extent - MARGIN));
  return { top: clamp(top, size.height, viewport.height), left: clamp(left, size.width, viewport.width) };
}
```

`TranslationParams` is `Record<string, string | number>` (`lib/i18n/types.ts:5`), so numeric params go through as they are.

```ts
export type ToolCallStatus = "running" | "done" | "failed" | "none";

/** null: no result yet but the run (or the streamed message) may still bring one, so nothing is claimed. */
export function toolCallStatus({ hasResult, isError, running, awaitingResult }: { hasResult: boolean; isError: boolean; running: boolean; awaitingResult: boolean }): ToolCallStatus | null {
  if (running) return "running";
  if (hasResult) return isError ? "failed" : "done";
  return awaitingResult ? null : "none";
}

export const TOOL_STATUS_GLYPH: Record<Exclude<ToolCallStatus, "running">, string> = { done: "✓", failed: "✕", none: "–" };

export const TOOL_STATUS_LABEL_KEY: Record<ToolCallStatus, string> = {
  running: "chat.toolStatus.running",
  done: "chat.toolStatus.done",
  failed: "chat.toolStatus.failed",
  none: "chat.toolStatus.noResult",
};

/** The previous set while the ids are the same members, so a memoized consumer skips progress ticks. */
export function stableIdSet(previous: ReadonlySet<string>, ids: readonly string[]): ReadonlySet<string> {
  const next = new Set(ids);
  if (next.size === previous.size && [...next].every((id) => previous.has(id))) return previous;
  return next;
}
```

```ts
export interface NextFireHint { everyInMinutes?: number | "soon"; dailyAt?: string }

/** Next scheduled fire as the scheduler computes it: an interval fire comes at the first tick of each epoch-aligned
 *  bucket (`floor(now / every)`, lib/agent-ops/scheduler.ts), so after a fire the next one is the next bucket's start;
 *  a feed's interval is a poll, not a fire. Daily `at` is the server clock, shown as written. */
export function nextFireHint(trigger: Pick<PublicTrigger, "enabled" | "everyMinutes" | "at" | "source">, lastFireAt: string | undefined, now = Date.now()): NextFireHint | null {
  if (!trigger.enabled) return null;
  const hint: NextFireHint = {};
  if (trigger.everyMinutes && !trigger.source) {
    const every = trigger.everyMinutes * 60_000;
    const last = lastFireAt ? Date.parse(lastFireAt) : Number.NaN;
    const next = (Math.floor(last / every) + 1) * every;
    hint.everyInMinutes = Number.isNaN(next) || next <= now ? "soon" : Math.ceil((next - now) / 60_000);
  }
  if (trigger.at) hint.dailyAt = trigger.at;
  return hint.everyInMinutes === undefined && hint.dailyAt === undefined ? null : hint;
}
```
